# Embeddable Widget & Lead-Capture Platform

Backend capstone for a multi-tenant embeddable widget platform. The system lets a widget owner manage lead-capture widgets, gives customers a one-line script snippet, accepts public submissions from a second origin, validates and protects those submissions, enriches them when possible, stores them in PostgreSQL, and exposes tenant-scoped dashboard APIs.

## Status

Initial project skeleton and design phase. Full setup, API reference, verification evidence, and clean-clone instructions will be completed as the implementation lands.
